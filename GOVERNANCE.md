# Governance

> Status: Early-stage governance
> Implementation: Maintainer assignments are not yet made

FinnOS uses maintainers for project stewardship, subsystem ownership, and architectural review. Decisions aim for documented, consensus-oriented outcomes. Unresolved decisions escalate to the maintainers for a recorded resolution.

Architecture proposals and changes to public system calls, kernel objects, IPC, security models, packages, or formats require an RFC. Security-sensitive decisions receive focused review and must not expose vulnerabilities publicly.

Maintainers are added or removed by an existing maintainer decision recorded in project history. One person may temporarily hold several roles, but architectural decisions should still be documented. See [planned ownership](MAINTAINERS.md).
