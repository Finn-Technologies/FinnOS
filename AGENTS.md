# FinnOS Agent Entry

All coding agents must begin with [`.agents/README.md`](.agents/README.md) and [`.agents/STATE.md`](.agents/STATE.md), then select task-specific skills from [`.agents/MANIFEST.md`](.agents/MANIFEST.md). Repository code and executed tests outrank documentation. Every substantial task requires acceptance criteria, baseline reproduction, relevant tests/documentation, and a structured handoff.
