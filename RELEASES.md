# FinnOS Release Policy

> Status: Policy for future releases
> Implementation: No system release exists

Future channels may include nightly, preview, beta, and stable. No FinnOS system release currently exists; the repository version is not an operating-system release. Pre-1.0 interfaces may change.

Before public stability promises, application, driver, IPC, package, and on-disk compatibility policies will be established. Example future versions are `0.1.0-preview`, `0.5.0-beta`, and `1.0.0`. The existing `first-boot-x86_64-v0.1` tag is a development milestone, not an OS release. See [RELEASING.md](RELEASING.md).
