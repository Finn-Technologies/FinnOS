# Security Policy

> Status: Temporary pre-release process
> Implementation: No dedicated private security contact is configured

FinnOS is experimental and is not suitable for protecting sensitive production systems. Do not initially disclose a security issue through a public issue when it could endanger future users. Until a dedicated contact exists, contact the repository owner privately through the hosting platform. This placeholder process must be replaced before any public binary release.

Reports should include the affected component, reproduction information, impact, and a suggested mitigation when known.
