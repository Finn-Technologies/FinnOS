# Release Readiness

- [ ] Apply every gate in `RELEASING.md` and `stable-release-readiness` skill.
- [ ] Verify debug/release, x86/ARM parity, clean install/update/rollback/recovery.
- [ ] Qualify userspace, storage, network, UI/accessibility, security, and hardware scope.
- [ ] Rebuild reproducibly; produce hashes, signatures, SBOM, and provenance.
- [ ] Publish supported versions/platforms, known issues, migration, EOL, and response policy.
- [ ] Require zero open release P0/P1 and independent verification where feasible.
- [ ] Never treat the first-boot tag as an OS release.
