# UI Review

- [ ] Confirm Peony prerequisites exist; mockups/proposals are labeled planned.
- [ ] Use semantic tokens and documented type/spacing/geometry scales.
- [ ] Verify default, hover, pressed, focus, selected, disabled, busy, invalid states.

- [ ] Include loading, empty, offline, permission, partial, and error states.
- [ ] Capture screenshots, performance/input latency, and usability evidence.
