# Pre-Commit

- [ ] Inspect `git status`, complete diff, and recent commit style.
- [ ] Remove unrelated/generated artifacts and local absolute paths.
- [ ] Scan for credentials, tokens, private data, debug hacks, TODO/FIXME additions.
- [ ] Run `git diff --check`, agent validation, narrow tests, and required gates.
- [ ] Confirm docs and skill registry are synchronized.
- [ ] Group logical commits; use `area: imperative summary`.
- [ ] Record exact files, commands, results, and unverified limitations.
