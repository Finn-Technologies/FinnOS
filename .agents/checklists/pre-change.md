# Pre-Change

- [ ] Identify existing invariants, unsafe boundaries, and capacity limits.
- [ ] Trace callers, failure paths, logs, tests, and generated artifacts.
- [ ] Map shared policy and x86-64/ARM64 mechanisms.
- [ ] Confirm roadmap dependency and active-work overlap.
- [ ] Define smallest correct change and rollback.
- [ ] Add a regression test that fails for the observed defect where feasible.
- [ ] Record required docs/status updates.
