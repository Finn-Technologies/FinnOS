# Architecture Decision Records

> Status: Decision history
> Implementation: Initial direction is recorded below

An ADR records a decision and its tradeoffs. Statuses are Proposed, Accepted, Rejected, and Superseded. Accepted ADRs should not be silently rewritten; later decisions supersede earlier ones. Small corrections are allowed when they do not change the decision.
